### Packages

- **fabrik_theme** — design tokens, typography scale, colors, and `MaterialApp` theming
- **fabrik_layout** — responsive layout context, breakpoints, and device-aware text scaling
- **fabrik_snackbar** — production-ready snackbars and toasts with semantic variants
- **fabrik_forms** — UI-agnostic form state, validation, and reactive `ValueNotifier` API
- **fabrik_utils** — DateTime, String, duration, debounce, throttle, and scroll helpers
- **fabrik_result** — lightweight `Either` and `Unit` types for functional error handling
